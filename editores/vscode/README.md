# Tangerine para VS Code

Colores de sintaxis, fragmentos y ajustes de edición para archivos `.tng` del lenguaje [Tangerine](https://www.npmjs.com/package/tangerine-lang).

- Resalta palabras clave, strings con interpolación `{...}`, números, rangos, closures y funciones incluidas.
- Cierra llaves, corchetes y comillas, y comenta con `Ctrl+/`.
- Fragmentos: `fn`, `class`, `match`, `for`, `fore`, `do`, `import`, `pl`, `comp` (componente de React).

Instálala con el CLI de Tangerine:

```bash
tangerine vscode
```
